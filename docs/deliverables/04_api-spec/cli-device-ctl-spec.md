# 操作仕様書 — device-ctl

| 項目 | 内容 |
|---|---|
| ドキュメント番号 | OPS-CLI-001 |
| バージョン | 1.0 |
| 作成日 | 2026-06-01 |
| 対象バイナリ | `device-ctl` |

> MCP3008（8ch / 10bit SPI ADC）の各チャネルを読み出す**動作確認・デバッグ用 CLI**。
> 内部では `libsensor` の `Sensor` クラスを使う。内部実装は [詳細設計（DES-CLI-001）](../03_detailed-design/cli-design.md) を参照。

---

## 1. 概要 / 用途

起動時に SPI デバイスをオープンし、**対話メニュー**で「チャネル指定読み出し」「全チャネルスキャン」を行う。加えて 1 分ごとに CH0 を読むバックグラウンドモニタを表示する。

## 2. 起動方法・構文

```sh
device-ctl [OPTIONS]
```

起動後は対話モードに入り、標準入力からメニュー番号を受け付ける。標準入力が EOF になると終了する。

## 3. オプション一覧

| オプション | 引数 | 既定値 | 説明 |
|---|---|---|---|
| `-d` | `<device>` | `/dev/spidev0.0` | SPI デバイスパス |
| `--vref` | `<V>` | `3.3` | 基準電圧 [V]（電圧換算に使用）|
| `--async` | — | （同期）| メニュー[1]の読み出しを非同期モード（`read_raw_async`）で実行 |
| `--version` | — | — | バージョン情報（cli / libsensor / spi-hal / commit / build 日時）を表示して終了 |
| `-h` | — | — | ヘルプ（usage）を表示して終了 |

> オプションは先頭の `-` で始まる引数のみ解釈する。未知のオプション・余分な引数はエラー終了する（§6）。

## 4. 対話メニュー

```
[1] チャネル指定読み出し
[2] 全チャネルスキャン
[3] 終了
選択:
```

| 選択 | 動作 |
|---|---|
| `1` | チャネル番号（0〜7）を入力 → 当該チャネルを読み出す（`--async` 指定時は非同期）|
| `2` | CH0〜CH7 を順に読み出す |
| `3` | 終了 |
| その他 | 「無効な選択です」を表示して再入力 |

チャネル入力が 0〜7 以外、または数値でない場合は「無効なチャネルです（0〜7）。」を表示してメニューに戻る。

## 5. 入出力・表示フォーマット

### 5.1 起動バナー（標準出力）

起動時にデバイスパスと基準電圧（Vref）を表示するバナーが出力される。

```
device-ctl 対話モード (デバイス: /dev/spidev0.0, Vref=3.30 V)
```

### 5.2 読み出し結果（標準出力）

```
CH0  raw=512  voltage=1.650 V
```

- `raw`: 10bit 生値（0〜1023）
- `voltage`: `raw * Vref / 1023` を小数 3 桁で表示

### 5.3 非同期読み出し失敗時（標準エラー）

`--async` モードでの読み出しが失敗した場合、以下のフォーマットでエラーと `errno` が出力される。

```
async read error: <errno>
```

### 5.4 同期読み出し失敗時（標準エラー）

同期モード（通常モード）での読み出しが失敗した場合は、以下のフォーマットで出力される。

```
CH0 read failed
```

### 5.5 バックグラウンドモニタ（標準出力）

1分ごとにバックグラウンドで CH0 が読み出され、次のメニュー表示の直前に出力される。

- **成功時**:
  ```
  [MONITOR] CH0 raw=512 voltage=1.650 V
  ```
- **失敗時**:
  ```
  [MONITOR] CH0 read failed
  ```
  ※バックグラウンドモニタの読み出し失敗メッセージは標準出力（stdout）に出力される（標準エラーではない）。

### 5.6 無効な入力時の警告メッセージ

- **対話メニューで無効な選択（1〜3 以外）を入力した場合（標準出力）**:
  ```
  無効な選択です。もう一度入力してください。
  ```
- **チャネル番号（0〜7 以外、または数値以外）で無効な入力をした場合（標準エラー）**:
  ```
  無効なチャネルです（0〜7）。
  ```

## 6. 終了コード

| コード | 意味 |
|---|---|
| `0` | 正常終了（メニュー[3] / 標準入力 EOF / `--version` / `-h`）|
| `1` | 異常終了：未知のオプション、`--vref` が数値でない、余分な引数、デバイスを開けない |

## 7. 使用例

```sh
# デフォルト（/dev/spidev0.0, Vref 3.3V）で起動
device-ctl

# デバイスパスを指定
device-ctl -d /dev/spidev0.1

# Vref 5.0V を指定
device-ctl --vref 5.0

# 非同期 read モードで起動
device-ctl --async

# バージョン確認
device-ctl --version
```
