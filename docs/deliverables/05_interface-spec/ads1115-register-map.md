## 1. アドレス指定

7bit スレーブアドレスは `ADDR` ピンの接続先で決まる。

| ADDR 接続先 | アドレス |
|---|---|
| GND | `0x48`（既定）|
| VDD | `0x49` |
| SDA | `0x4A` |
| SCL | `0x4B` |

ALERT/RDY ピンは変換完了通知（RDY）に利用でき、GPIO 割り込みと組み合わせられる（§6）。

## 2. レジスタマップ

ADS1115 は 4 レジスタを持つ。アクセスは「**レジスタポインタを書く → 読む**」形式で、読み出しはリピーテッドスタートを使う（`I2cDriver::write_read`）。

| ポインタ | 名称 | R/W | 説明 |
|---|---|---|---|
| `0x00` | Conversion | R | 変換結果（符号付き 16bit）|
| `0x01` | Config | R/W | 変換開始・チャネル・ゲイン・モード等 |
| `0x02` | Lo_thresh | R/W | コンパレータ下限 / RDY 用 |
| `0x03` | Hi_thresh | R/W | コンパレータ上限 / RDY 用 |

各レジスタは 16bit（MSB first）。書き込みは `[ ptr, MSB, LSB ]` の 3 バイト。

## 3. Config レジスタ（0x01）ビットフィールド

| bit | 15 | 14:12 | 11:9 | 8 | 7:5 | 4 | 3 | 2 | 1:0 |
|---|---|---|---|---|---|---|---|---|---|
| フィールド | OS | MUX | PGA | MODE | DR | COMP_MODE | COMP_POL | COMP_LAT | COMP_QUE |

| フィールド | 本実装での値 | 意味 |
|---|---|---|
| OS (15) | 書込 `1`=変換開始 / 読出 `1`=変換完了 | `CFG_OS_SINGLE = 0x8000` |
| MUX (14:12) | シングルエンド `0b100` + ch | `0x4000 \| (channel << 12)`（A0=100…A3=111）|
| PGA (11:9) | ゲイン（§5）| `(gain & 0x07) << 9` |
| MODE (8) | `1`=シングルショット | `CFG_MODE_SINGLE = 0x0100` |
| DR (7:5) | `0b100`=128 SPS | `CFG_DR_128SPS = 0x0080` |
| COMP_QUE (1:0) | `0b11`=無効 / `0b00`=1変換でアサート（RDY 用）| `0x0003` / `0x0000` |

**組み立て例**（CH0, ±2.048V, 128SPS, コンパレータ無効）:

```
OS(0x8000) | MUX_A0(0x4000) | PGA_2.048V(0x0400) | MODE_single(0x0100)
          | DR_128SPS(0x0080) | COMP_QUE_disable(0x0003) = 0xC583
```

（この値は単体テスト `UT-ADS-006` で検証。）

## 4. シングルショット変換シーケンス（`Ads1115::read_raw`）

```
1. Config(0x01) に上記 16bit を書く（OS=1 で変換開始）
2. 変換完了待ち: Config を読み、OS ビット(bit15)が 1 に戻れば完了
   （本実装は最大 16 回・500us 間隔でポーリング）
3. Conversion(0x00) を読む → 符号付き 16bit
```

## 5. ゲイン（PGA）とフルスケール電圧

| Gain | PGA(11:9) | フルスケール [V] |
|---|---|---|
| FSR_6_144V | 000 | ±6.144 |
| FSR_4_096V | 001 | ±4.096 |
| FSR_2_048V | 010 | ±2.048（既定）|
| FSR_1_024V | 011 | ±1.024 |
| FSR_0_512V | 100 | ±0.512 |
| FSR_0_256V | 101 | ±0.256 |

変換式（符号付き 16bit のフルスケールは 32768）:

```
voltage = raw * full_scale_volts() / 32768
```

## 6. ALERT/RDY（変換完了通知）

`Hi_thresh` の MSB=1（`0x8000`）/ `Lo_thresh` の MSB=0（`0x0000`）を書き込むと、ALERT/RDY ピンが変換完了通知として機能する（`Ads1115::enable_conversion_ready_pin`）。このとき Config の `COMP_QUE` は無効(`0b11`)ではなくアサート有効(`0b00`)にする。

GPIO 割り込みとの連携は [GPIOラインIF仕様書（IF-GPIO-001）](gpio-line-if.md) を参照。
