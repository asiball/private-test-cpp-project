---

## 1. 物理インターフェース

| 信号名 | 方向 | RPi 3B+ ピン | 説明 |
|---|---|---|---|
| SDA | 双方向（オープンドレイン）| GPIO2 (Pin 3) | シリアルデータ |
| SCL | Master → Slave（オープンドレイン）| GPIO3 (Pin 5) | シリアルクロック |
| GND | — | Pin 6 等 | 共通グランド |

> SDA / SCL は**オープンドレイン**で、バスに**プルアップ抵抗**（通常 3.3V へ 4.7kΩ 程度）が必要。
> Raspberry Pi のオンボード I2C（i2c-1）は内蔵プルアップを持つ。

## 2. 電気的仕様

| 項目 | 仕様 |
|---|---|
| 論理電圧 | 3.3V |
| バス方式 | オープンドレイン + プルアップ |
| 速度 | Standard-mode 100 kbit/s ／ Fast-mode 400 kbit/s |
| 相手の選択 | 7bit スレーブアドレス（CS ピンは不要）|

## 3. プロトコル（トランザクション）

I2C はハーフデュプレクス。1 トランザクションは以下で構成される。

```
[START] [addr(7bit)+R/W] [ACK] [data ...] [ACK/NACK] ... [STOP]
```

レジスタ参照（書いてから読む）は、途中で STOP せず **リピーテッドスタート**でつなぐ:

```
[START] addr+W, reg [REPEATED START] addr+R, data... [STOP]
```

これは `I2cDriver::write_read()`（`I2C_RDWR`）が 1 トランザクションで行う（IF-I2C 観点での要点）。

## 4. アドレッシング

7bit アドレスでスレーブを選ぶ。例：ADS1115 は `ADDR` ピンの接続先でアドレスが決まる。

| ADDR 接続先 | アドレス |
|---|---|
| GND | `0x48` |
| VDD | `0x49` |
| SDA | `0x4A` |
| SCL | `0x4B` |

## 5. Linux i2c-dev ioctl 一覧

| コマンド | 用途 |
|---|---|
| `I2C_SLAVE` | 以降の `read`/`write` の宛先スレーブアドレスを設定 |
| `I2C_RDWR` | 複数の `i2c_msg` を 1 トランザクションで送受信（リピーテッドスタート対応）|

`I2C_RDWR` で渡す構造体:

```c
struct i2c_msg {            // 1 メッセージ
    __u16 addr;             // スレーブアドレス
    __u16 flags;            // 0=書き込み, I2C_M_RD=読み出し
    __u16 len;              // バイト数
    __u8 *buf;              // データ
};
struct i2c_rdwr_ioctl_data { // メッセージ群
    struct i2c_msg *msgs;
    __u32 nmsgs;            // write_read では 2（書き込み + 読み出し）
};
```
